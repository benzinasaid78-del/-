تعذر الاتصال بقاعدة البيانات

{
  "rules": {
    "products": {
      ".read": true,
      ".write": true
    }
  }
}

اضغط لتحميل المنتجات التي أدخلناها (باركودات وأسماء وما كُتب من أثمان) إلى قاعدة البيانات مرة واحدة.
